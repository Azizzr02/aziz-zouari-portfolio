SEGULA Technologies · Final-year project · 2026

CAN-FD battery management test bench

I built an STM32 firmware emulator and a Linux supervision path to exercise BMS-style temperature telemetry, state transitions, and fault handling on a bench.

Embedded CSTM32G0B1RESocketCANPython
STM32ADC · state machine
CAN-FDTelemetry · commands
Raspberry PiDecode · visualize
Read the case study

A timer gates the application loop at 10 Hz. The firmware filters analog readings, estimates temperature and its rate of change, and packs the health state into an eight-byte CAN-FD telemetry frame. A UART status line exposes the decoded fields and frame counters during bring-up.

On the Pi, SocketCAN receives the frames and the backend decodes them using a DBC file. FastAPI serves the React dashboard and streams live updates over WebSocket. The bench also supports commands for repeatable fault-handling tests.

I wrote Python and shell tooling for test execution and data capture, and documented the bench setup and validation procedures.

Team prototype · 2025

Vision-to-control ADAS

With Oussema, I built a prototype that connects YOLOP computer vision to STM32 motor control through a Yocto Linux gateway.

YOLOPYocto LinuxCANSTM32F407
LaptopYOLOP inference
Yocto PiUDP to CAN
STM3250 Hz PWM
Read the case study

The laptop derives lane offset and distance from camera input and sends the results to a Raspberry Pi 4 over UDP. The Pi runs a custom Yocto image with SocketCAN and bridges the messages onto the CAN bus.

The STM32F407 generates 50 Hz PWM for the motor controller. Running perception, protocol translation, and actuation on separate devices let us validate the end-to-end path from camera input to motor response.

CAN ECU for thermal monitoring

I designed and assembled a dual-STM32 bench system for automotive thermal management, from schematic capture and PCB layout to board bring-up.

STM32Altium DesignerADCPWM
